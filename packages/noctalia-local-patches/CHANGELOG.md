# Noctalia 本地补丁版本

上游：Noctalia v5.3.0，提交 `a33122c4208a385e19c9a252e65e2751b2c44fbb`。
`PKGBUILD` 和 `.SRCINFO` 记录源码来源及 SHA-256；补丁包独立安装到 `/usr/lib/noctalia-local-patches/`。

## 5.3.0.p2-1 — 2026-10-22

- 启动器分类按钮使用完整名称的自然宽度，空间不足时换行。
- 换行按钮采用独立圆角，分隔线不占用布局空间。
- 增加无界面布局回归，覆盖 260、560、1040 宽度与 1.0、1.5 缩放。
- 保留 p1 的网络、磁盘单位及托盘修改。

验证：构建、布局回归及原有桌面补丁检查通过，已安装并检查实际启动器。
当前桌面配置选择隐藏分类栏；这项用户偏好由仓库中的 `zz-launcher.toml` 管理，不改变补丁版本。

## 5.3.0.p1-1 — 2026-10-21

- 网络页面显示物理有线网卡、链路状态、速率、IP 和 MAC。
- IP 点击复制、已保存 Wi-Fi 自动连接开关及有线优先路由设置。
- 磁盘容量采用十进制 GB。
- 托盘图标边距可配置，默认 1 个逻辑像素。
- 提供独立配置、状态、数据目录，以及补丁版和官方版切换入口。

此版本由独立项目迁入前维护；本仓库从 p2 开始保存完整构建入口。
